#  What is YouMatter?

**YouMatter** is an AI-powered mental health companion and lab report interpreter built to make emotional support and healthcare guidance accessible to everyone.

It helps users:

- Talk to an empathetic AI companion
- Track mood and emotions
- Maintain a private journal
- Practice calming breathing exercises
- Understand medical lab reports in simple language

---

#  Features

## 💬 AI Mental Health Companion

- Supportive AI conversations
- Mood-aware responses
- Calm and empathetic interaction
- Guided reflection support

---

##  Lab Report Interpreter

Upload blood test or medical reports and receive:

- Simplified explanations
- High/low parameter detection
- Easy-to-understand summaries
- Important questions to ask doctors

---

##  Guided Breathing Exercises

Built-in breathing modes:

- Box Breathing
- 4-7-8 Breathing
- Deep Calm Sessions

---

##  Private Mood Journal

- Daily journaling
- Mood tagging
- Emotional tracking
- Personal reflections

---

##  Mood Analytics

- Mood trends
- Emotional history
- Weekly insights
- Visual progress tracking

---

##  Crisis Support

Built-in crisis assistance with emergency resources and helplines.

#  Getting Started

## 1. Clone Repository

```bash
git clone your-repository-url
cd youmatter
```

---

## 2. Install Dependencies

### Frontend

```bash
cd frontend
npm install
```

### Backend

```bash
cd backend
npm install
```

---

## 3. Environment Variables

Create `.env` files.

### Frontend `.env`

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_anon_key
VITE_API_BASE_URL=http://localhost:5000
```

### Backend `.env`

```env
PORT=5000

SUPABASE_URL=your_supabase_url
SUPABASE_SERVICE_ROLE_KEY=your_service_role_key

GROQ_API_KEY=your_groq_api_key
JWT_SECRET=your_secret
```

---

## 4. Run Project

### Frontend

```bash
npm run dev
```

### Backend

```bash
npm start
```
